# PMF Superpowers

The Sequoia Arc PMF framework, encoded as auto-triggering, gated, rationalization-resistant skills for your coding agent.

> **Status:** v0.1.0 — Day 1 scaffolding. Bootstrap meta-skill working. Question-skills and corpus arriving Days 3-4.

## What this is

A plugin for Claude Code, Codex CLI, Cursor, OpenCode, Gemini CLI, GitHub Copilot CLI, and Factory Droid. When you open a session and start describing your startup, the plugin auto-triggers a sequence:

1. **Archetype detection** — Hair on Fire / Hard Fact / Future Vision (Sequoia's framework). The plugin refuses to proceed without an archetype on record.
2. **The Four Terrifying Questions** — Q1 *Right to exist* → Q2 *Do people care enough?* → Q3 *Does product change behavior?* → Q4 *Pay enough?*. Each is a stage gate with resolution criteria, not a checkbox.
3. **Refusal at threshold** — claim Q2 resolved with 8 cold conversations? The plugin says no, returns the evidence gap, refuses to advance.
4. **Founder-rationalization defense** — a table of the 20-25 most common excuses founders use to skip discipline, with counters drawn from Sequoia, The Mom Test, Steve Blank, and April Dunford.
5. **Corpus retrieval** — surfaces analogous iconic-startup cases (Stripe, DoorDash, Notion, Linear, etc.) indexed by archetype × question × decision shape.

The refusal is the product.

## Why this exists

Sequoia, Rob Fitzpatrick (Mom Test), Steve Blank (Customer Development), April Dunford (positioning) — all of these published frameworks decades ago. Founders still skip them. The frameworks tell you what to do; they don't enumerate the 20-25 rationalizations you'll use to talk yourself out of it.

This plugin enumerates them. With counters. As gates the agent must pass before claiming resolution.

## How it's built

The system has two layers:

| Layer | Build method | Why |
|---|---|---|
| **Meta-skills** (`using-pmf-superpowers`, `archetype-detection`, `refuse-below-threshold`, `founder-rationalization-defense`, `corpus-retrieval`) | Hand-authored | Adversarial gating language needs precision tuning. New IP. |
| **Question-skills** (`arc-q1-right-to-exist`, `arc-q2-do-people-care`, future Q3/Q4) | Generated by [EnactSkill](https://enactskill.com) `/generate` | Sequoia, Mom Test, Blank, Dunford did the adversarial testing decades ago. EnactSkill renders to SKILL.md shape with gating attached. |
| **Corpus** (case files indexed by archetype × question) | Generated by EnactSkill | Founder retrospectives, structured per the schema in `skills/corpus-retrieval/`. |

Each generated artifact carries a receipt: *"Generated by EnactSkill `/generate` from <source URL>."*

## The product behind the plugin

This plugin is the open-source distribution surface for [EnactSkill](https://enactskill.com), which generates personalized PMF artifacts from a founder's actual inputs — their pitch deck, current users, sales-call transcripts. The plugin gives you the framework; EnactSkill customizes the artifact.

Free plugin, paid generator. Same pattern as Next.js → Vercel.

## Acceptance test

A working integration auto-triggers the bootstrap on session start. Open a clean session in your harness and send:

> Let's find product-market fit for my startup

The plugin should immediately ask for archetype determination, refuse to proceed without one, and route to the right Q-skill.
